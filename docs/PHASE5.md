# Phase 5 — Experimental validity status

The prior result tables referenced missing connectivity-aware workload modules.
They have been removed.

Before publishing cross-protocol conclusions, experiments should provide:

- a workload fingerprint shared across protocols in each scenario/seed cell;
- uncertainty intervals over independent stochastic workloads;
- a documented, provenance-bearing TLE snapshot or clearly labelled synthetic data;
- an ISL degree/port constraint, so control overhead is not a consequence of an
  unrealistically dense geometric graph.

Synthetic constellations are not operational Starlink.
