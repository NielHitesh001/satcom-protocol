Inspection of `engine.py`, `routing/aodv.py`, `routing/olsr.py`, `routing/practical_predictive.py`, `metrics.py`.

| Message | Counted | Size on packet | Uses `_send` | Serialization | Propagation | Shares link busy time | Queue limit | Loss applied | Loss counted |
|---------|---------|----------------|--------------|---------------|-------------|------------------------|-------------|--------------|--------------|
| AODV RREQ | yes, fanout at emit and on forward | hardcoded 64 | yes (broadcast) | yes | yes | yes | no (DATA only) | yes | no |
| AODV RREP | yes, 1 per unicast hop accounted | hardcoded 64 | yes | yes | yes | yes | no | yes | no |
| AODV RERR | yes, 1 per target | 48+8×dests | yes | yes | yes | yes | no | yes | no |
| OLSR HELLO | yes, `max(1, degree)` at tick | hardcoded 48 | yes (broadcast) | yes | yes | yes | no | yes | no |

| Practical LINK_NOTIFY | +1 per link event, no packet | none | no | no | no | no | no | no | no |

`RunMetrics.control_bytes_sent` existed and stayed 0. Queue policy was already DATA-only; it was **not** changed.

Generation counts are **logical fanout**, not a guaranteed count of successful airtime transmissions. Airtime can be higher (extra forwards) or lower (broadcast into an empty neighbor set, or loss before scheduling).

## 2. Size model (configurable assumptions)

Module: `routing/control_sizes.py` (`ControlSizeModel`).

| Field | Default bytes | Role |
|-------|---------------:|------|
| aodv_rreq | 64 | RREQ PDU |
| aodv_rrep | 64 | RREP PDU |
| aodv_rerr_base + per_dest | 48 + 8×N | RERR PDU |
| olsr_hello | 48 | HELLO PDU |
| olsr_tc | 64 | TC PDU |
| practical_refresh_per_node | 32 | **estimate only**, not transmitted |

**Included:** one modeled control PDU used for `serialization_s = size_bytes * 8 / (capacity_mbps * 1e6)`.  
**Not included:** separate network header, link header, PHY overhead.  
**Not** a hardware measurement. Scenario key `control_sizes` overrides fields; omitted keys keep defaults. The dict is copied into `summary_dict()["control_size_model"]`.

Defaults match the previous hardcoded integers, so default scenarios do not change sizes.

## 3. What is measured vs estimated

| Field | Meaning |
|-------|---------|
| `control_sent` | unchanged logical message count |
| `control_bytes_sent` | generation bytes for messages marked airtime (count × PDU size at accounting time) |
| `control_bytes_by_type` / `control_msgs_by_type` | same split by RREQ, RREP, RERR, HELLO, TC, REFRESH, LINK_NOTIFY |
| `control_airtime_bytes` | sum of `size_bytes` for control PDUs **scheduled** in `_send` (one count per directed transmission) |
| `control_airtime_tx` | number of those transmissions |
| `control_loss_tx` | control transmissions dropped by Bernoulli loss **before** serialization |
| `control_serialization_s` | sum of serialization delays of scheduled control transmissions |
| `control_bytes_estimated_not_airtime` | practical predictive refresh (and zero-size link notifies) |
| `data_bytes_injected` | sum of injected DATA sizes |
| `control_to_data_byte_ratio` | airtime control bytes / injected data bytes, or null |

`control_serialization_s` is modeled airtime, not RF occupancy. Queue limit still ignores control.

## 4. Protocol cost on one synthetic cell

N=30 Walker, duration 40 s, seed 42, max_range 5000 km, rate 0.5 pkt/s, 512 B data, capacity as noted. Fixed endpoints `SYN-LEO-90001` → `SYN-LEO-90015` (may be disconnected).

| Protocol | Delivery | control_sent | generated bytes | airtime bytes | estimated non-airtime | serialization_s @ 10 Mbps | @ 100 Mbps |
|----------|----------|-------------:|----------------:|--------------:|----------------------:|-----------------------:|-----------:|
| predictive (oracle) | 0.615 | 0 | 0 | 0 | 0 | 0 | 0 |
| practical_predictive | 0.615 | 170 | 0 | 0 | 2880 | 0 | 0 |
| aodv | 0.000 | 5 | 320 | 512 | 0 | 4.1e-4 | 4.1e-5 |
| olsr | 0.462 | 7413 | 449248 | 651296 | 0 | 0.521 | 0.052 |

AODV delivery 0 means these fixed endpoints had no usable route in this geometry — not a change in residual accounting. Conservation held (`conservation_ok` true on every row).

OLSR airtime bytes exceed generation bytes because each scheduled hop is counted in the engine, while generation counts fanout at the emitter. Both are reported; neither is suppressed.

Practical predictive’s 2880 B is `32 ×` refresh-node counts. It does **not** consume link busy time.

Oracle zero-control is not a deployable cost.

## 5. Sensitivity method

`experiments/phase6_sensitivity.py` varies **one** factor from a fixed baseline. Protocols in the same factor/value share `workload_fp` (scenario JSON without protocol name).

Baseline: range 5000 km, 100 Mbps, loss 0, queue 64, step 15 s, 0.5 pkt/s, 512 B.

Small matrix actually executed (N=30, 40 s, seed 42, predictive + AODV):

| Factor | Value | Predictive delivery | AODV delivery | Notes |
|--------|------:|--------------------:|--------------:|-------|
| time_step_s | 15 | 0.615 | 0.000 | fp matched across protocols |
| time_step_s | 30 | 0.000 | 0.000 | coarser snapshots; oracle path disappeared |
| capacity_mbps | 10 and 100 | 0.615 | 0.000 | delivery unchanged; AODV serialization scaled ×10 |
| loss_prob | 0 | 0.615 | 0.000 | |
| loss_prob | 0.05 | 0.462 | 0.000 | oracle delivery fell; Bernoulli on DATA |

Topology is updated only at `time_step_s` snapshots. The engine does **not** move satellites continuously between snapshots. Event order and `sent = delivered + dropped + residual` held on these rows.

Two seeds were not used here. Do not rank protocols from this single constellation and seed. Student-t summaries remain available via `experiments/stats_summary.py` when a CSV has repeated seeds.

## 6. Resource

Sensitivity wall time per cell was about 0.4–0.7 s (AODV/oracle) and about 0.9–1.2 s (OLSR) at N=30. No extra per-event logs were stored. RSS was not a limiting factor on this 4 GB host for these cells.

## 8. Limitations

- Sizes are assumptions, not wire formats or RFC PDUs.
- Control does not use a separate priority queue; it shares serialization busy time and skips the DATA queue cap.
- Practical predictive cost is an estimate, not airtime.
- OLSR volume was not reduced.
- Fixed endpoints on this Walker draw are often disconnected for AODV; that is a topology outcome.
- Results are one synthetic constellation, one seed, short duration.
- This host is not the 1.29 GB environment from Phases 4–5.
